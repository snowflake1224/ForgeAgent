It checks that orchestration finishes. It does not show general software-engineering ability. The case study is on the portfolio, and the source is on GitHub.

What the system is

ForgeAgent runs one repository task through four architectures so the architecture is the thing that changes. Tools, budgets, and the task stay the same. Every path stops at a limit on iterations, tool calls, tokens, and wall-clock time.

  • A_single_agent — one role runs the whole pipeline.
  • B_planner_coder — a planner hands work to a coder.
  • C_planner_coder_reviewer — a reviewer is added before the patch is accepted.
  • D_specialized_multi_agent — planner, repository analysis, coding, test, debugging, and review are separate roles.

Tools go through a registry with JSON Schema inputs, a deny-by-default policy, timeouts, and secret redaction. Generated patches still need a person to review them. If Docker is missing, execution fails closed unless a trusted local executor is chosen on purpose.
